**Three corrections the run forced:**

1. `sizeof(PlayerState)` is **560**, not 545. `Transform`/`Vector4` are
   `__declspec(align(16))`; `pack(1)` does not override it. Pads after
   `sceneCellId` (+4) and `destSpeed` (+8), and the struct rounds 557 → 560.
   Verified with `cl.exe` `offsetof` *and* live decode. A hand count was wrong by
   15 bytes and every packet was being dropped silently.
2. The log line is `[Net] init=`, not `[Net] up:` — the latter goes to
   `OutputDebugString` only.
3. `EntitySyncTick` returns at the `EntitySelfTest` branch **before** the host
   branch that calls `ProcessKillEvents`, so with the self-test on the game
   ignores incoming entity/kill packets. Kill lane blocked on config, not code.

**Armed:** `e0b_run.py` (pid 12972) waits for the next launch (`EntitySelfTest=0`
now in the ini) and then runs presence + a kill on the guard nearest the player.
